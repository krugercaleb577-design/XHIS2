Popular Solutions

Quick fixes for common incidents

My computer is running slowly

Follow these basic checks before submitting a performance-related ticket.

  1. Restart the computer.
  2. Close unused applications.
  3. Check available storage space.
  4. Contact the service desk if the problem continues.
COMPUTER

I cannot connect to the internet

Check the following before reporting a network connectivity problem.

  1. Check that Wi-Fi is enabled.
  2. Confirm other devices can connect.
  3. Restart the network connection.
  4. Submit a ticket if the issue remains.
NETWORK

I forgot my password

Follow the approved account recovery process before requesting technical assistance.

  1. Confirm your username.
  2. Use the approved password recovery option.
  3. Do not share your password with anyone.
  4. Contact IT if your account remains locked.
ACCOUNT

My printer is not working

Complete these basic checks before logging a printer support request.

  1. Confirm the printer is powered on.
  2. Check for paper or error messages.
  3. Check the print queue.
  4. Restart the printer if appropriate.
PRINTING

An application will not open

Basic application troubleshooting can resolve many software-related incidents.

  1. Close and reopen the application.
  2. Restart the computer.
  3. Check whether other applications work.
  4. Report the exact error message to IT.
SOFTWARE

Remote access is not working

Check the basic requirements for approved remote access.

  1. Confirm your internet connection.
  2. Verify your account credentials.
  3. Restart the approved VPN application.
  4. Contact IT if access remains unavailable.
